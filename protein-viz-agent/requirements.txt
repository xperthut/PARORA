# Structure preparation (prepare.py) needs nothing extra: it rewrites PDB
# records directly, deliberately avoiding ParmEd/pdb4amber, which are broken by
# NumPy 2 in current AmberTools builds. Adding hydrogens uses `reduce` from the
# same AmberTools installation the membrane tools discover.

# Simulation, QM and QM/MM setup (simulation.py, quantum.py, oniom.py).
# AmberTools again, discovered the same way as for the membrane tools: tleap
# builds the topology and antechamber/parmchk2 parameterise ligands, and both
# are run for real. Everything else -- GROMACS run files, Rosetta job files,
# Gaussian/ORCA/Psi4 and ONIOM inputs -- is generated, since none of those
# programs is installed here.
#
# RDKit is optional but strongly recommended: it is what protonates a ligand
# correctly, using the bond orders from the PDB chemical dictionary. Without
# it the fallback is `reduce`, which places hydrogens from idealised geometry
# and can leave a molecule chemically incomplete.
rdkit

# Secondary-structure/topology computation (topology.py, describe_fold's
# computed-topology half). NOT a pip dependency -- `mkdssp` is a single
# external binary, discovered at runtime via the DSSP_BIN environment
# variable or PATH. Its fold/topology database lookup half (CATH/SCOP via
# PDBe's SIFTS API) needs no extra dependency at all -- just `requests`,
# already above. Set up DSSP with:
#     conda create -n dssp -c conda-forge dssp
# conda-forge's dssp 4.x has been observed to segfault unpredictably on at
# least one arm64 macOS machine; dssp=3.1.4 was stable there
# (conda install -n dssp -c conda-forge "dssp=3" if 4.x misbehaves).

# Structure-based fold/homology search (structure_search.py,
# find_structural_neighbors and describe_fold's no-classification fallback).
# NOT a pip dependency -- `foldseek` is a single external binary, discovered
# at runtime via FOLDSEEK_BIN or PATH, and it needs a reference database
# (FOLDSEEK_DB, default protein-viz-agent/foldseek_db/pdb). Set up with:
#     conda create -n foldseek -c conda-forge -c bioconda foldseek
#     foldseek databases PDB protein-viz-agent/foldseek_db/pdb /tmp/fs
# The PDB database is ~2.2 GB to download, ~4.2 GB on disk.
